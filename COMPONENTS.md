# COMPONENTS
 To convert this CHIP-8 emulator (from desktop to being ported to ESP32), I need:
- ESP32 microcontroller ✅
- LCD/OLED:
    - ILI9341 TFT LCD (2.8" or 3.2", 240x320 resolution)
    - ST7789 TFT LCD
    - SSD1306 OLED (128x64)
- Input:
    - 16 tactile buttons arranged as 4x4 matrix (CHIP-8 keypad)
    - 4x4 membrane keypad
    - I2C/SPI joystick module with select button
- Micro SD Card Module (SPI interface) (this is for the ROM files)
- Breadboard and jumper wires ✅
- Power supply (USB or 3.7V LiPo battery)
